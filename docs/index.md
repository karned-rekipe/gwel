# Gwel

Gwel est l'interface Vue 3 de Rekipe. Elle couvre les recettes, les catalogues
d'ingrédients et d'équipements, la planification des repas et les courses.

Pour les recettes, la création assistée par IA est le parcours par défaut. Elle
accepte du texte, une URL de page ou d'image, ainsi qu'un document image/PDF.
La création manuelle reste disponible. Une fiche existante peut également être
enrichie par IA depuis sa page de détail.

Les traitements longs affichent un voile de progression qui reprend les phases
réelles publiées par l'agent et peut récupérer un run encore actif après un
rafraîchissement.
